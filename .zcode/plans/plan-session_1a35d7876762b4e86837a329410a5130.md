# OldOS_Android UI 改进方案（修订版）

## 已核实的事实（回应你的疑问）

1. **字体授权**：上游 OldOS README 只有 CC BY 4.0（覆盖作者创作内容），**没有 Helvetica Neue 字体的再授权说明**（该字体属 Linotype 商业字体，作者无权转授）。nos4 README 自述 "Type is set in Inter and Helvetica Neue"。→ **主字体改用 Inter（OFL 许可，可安全打包）**，显式配置 FontFamily 回退链（中文由系统 CJK 字体接管，校验混排行高字重）。
2. **nos4 数值出处已验证**：设计规格来自其源码 `packages/UIKit/src/<组件>/UI<Component>Metrics.ts`（已实测抓取 `StatusBar/UIStatusBarMetrics.ts`，确有 `rgb(237,244,247) 7% → rgb(191,199,203) 100%` 等原始值）及 `packages/SpringBoard/src/Support/SpringBoardMetrics.ts`。令牌文件中每个常量加注释标明出处。**只取数值参考，代码全部自己写**（nos4 无代码许可证）。
3. **2007.mobile**（iOS 1 仿真器）仅作交互手感参考，**不混用任何 iOS 1 素材**，避免两个时代质感冲突。

## Phase 1 — 设计系统（按你定的顺序）

1. **屏幕适配策略（置顶解决）**：采用**全屏拉伸**——320pt 设计基准按屏宽等比缩放，垂直延展（桌面行数自适应、应用列表可滚动），与真 OldOS 在现代 iPhone 上的行为一致；不用 3:2 画布+虚拟机身（20:9 屏会浪费近半空间）。Insets：适配 Android 15 强制 edge-to-edge，状态栏区域吞掉刘海（20pt 高度带内居中避让 cutout），底部假下巴用 `setSystemGestureExclusionRects` 排除手势冲突并隐藏手势指示条。
2. **字体**：打包 Inter Regular/Medium/Bold → `res/font`；`Type.kt` 重建全字阶（状态栏 12sp、导航标题 18sp bold、按钮 11sp bold、图标标签 11sp、表格行 17sp、分组头 17sp 蓝灰大写、锁屏时钟大号细体）；FontFamily 显式回退链 Inter → 系统 sans-serif（CJK），通讯录/短信中文渲染检查。
3. **`IOS4Palette.kt` 中央令牌**：收编散落 15 个文件的所有渐变（状态栏双形态、导航栏、按钮蓝/红、细条纹、开关、TabBar 选中蓝光等），每条注明 nos4 出处。
4. **状态栏双形态**：应用内浅灰渐变（黑字），桌面/锁屏半透明黑；Canvas 手绘信号条/WiFi/电池/放大镜/箭头，清除全部 Material `Icons.Default.*` 穿帮。
5. **pinstripe 细条纹**：预生成小尺寸 `ImageBitmap` tile + `ShaderBrush` 平铺（不逐帧画线），替换设置页纯色底。
6. **按压反馈**：导航按钮、列表行（iOS 4 蓝色选中渐变）、计算器键、锁屏滑块。
7. **Roborazzi 截图测试基建**：每屏 @Preview + 截图任务（无设备也能验证），截图与 nos4 官方截图并排对照，作为各阶段验收手段。

**验收**：桌面/锁屏/设置页截图 vs nos4.fun 截图并排比对 + 编译通过。

## Phase 2 — 桌面/锁屏精修

Spotlight 真搜索（应用+联系人，交替行背景）、锁屏与桌面字体统一、页面切换动画对齐 0.32s、图标阴影/倒影微调。

## Phase 3 — 逐个应用补全（每个应用独立 commit + 截图验证）

顺序（由轻到重）：**Settings 子页 → 时钟 → 便签（本地文件持久化）→ 计算器收尾 → 天气（接 Open-Meteo 真实数据，免费无 key）→ 通讯录（真实联系人+详情页）→ 照片 → iPod → Safari**。股票保持静态并标注 demo（后续再加）。

- 权限修正（minSdk 26）：`READ_EXTERNAL_STORAGE`(maxSdk 32) + `READ_MEDIA_IMAGES`/`READ_MEDIA_AUDIO`(33+) + `READ_MEDIA_VISUAL_USER_SELECTED`(34+，处理"仅允许部分照片") + `INTERNET`；**不加 READ_PHONE_STATE**——信号格保持静态，状态栏只接真实电量和运营商名；Wi-Fi 状态用 `ACCESS_NETWORK_STATE`。
- iPod 接真实播放后，多任务托盘的上一首/播放/下一首同步接通。

## Phase 4 — 系统真实感 + README 修正

- 状态栏真实数据：电量/充电状态（BatteryManager）、运营商名（TelephonyManager，无需权限）。
- `SettingsManager` 改 **DataStore** 持久化（重启不丢壁纸/开关）。
- About 页接真实数据：Build.MODEL、StatFs 真实容量、MediaStore 歌曲数。
- **README 修正**：删除 "pixel-perfect" 表述；新增 Credits/授权段——代码 MIT、PNG 资产来自 The OldOS Project (CC BY 4.0)、字体 Inter (OFL)、Apple 商标与设计版权归属声明、nos4 数值参考致谢。

- 每阶段/每应用独立 commit。
